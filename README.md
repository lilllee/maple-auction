# 메이플스토리 경매장 감시 알리미

메이플스토리 PC 경매장(https://auction.maplestory.nexon.com)에서 `.env`에 적은 매물 조건 하나를 정해진 간격으로 검색합니다. 상위 N건(기본 3건)이 바뀌면 카카오톡 "나에게 보내기"로 알려 줍니다. 근무 시간 중 회사 Windows PC에서 돌리는 용도입니다.

## 준비물

- Windows PC와 Node.js LTS 버전 (프로젝트는 Node.js 18.18 이상을 요구합니다)
- 넥슨 계정: OTP 연동 필수, 그린메이플ID 등록 필요
- 카카오 개발자 계정

## 설치와 설정 순서

1. Node.js LTS 버전을 설치합니다. 설치 후 새 PowerShell 창에서 `node -v`로 확인합니다.

2. 프로젝트 폴더에서 패키지를 설치합니다.

```powershell
npm install
```

3. 자동화에 쓰는 Chromium 브라우저를 설치합니다.

```powershell
npx playwright install chromium
```

4. 카카오 개발자 앱을 만듭니다.
   1. https://developers.kakao.com에 로그인하고 [내 애플리케이션 > 애플리케이션 추가]로 앱을 만듭니다.
   2. [앱 설정 > 앱 키]에서 REST API 키를 복사해 둡니다.
   3. [제품 설정 > 카카오 로그인]을 활성화하고, 리다이렉트 URI에 `http://localhost:3131/oauth`를 등록합니다.
   4. [제품 설정 > 카카오 로그인 > 동의항목]에서 `카카오톡 메시지 전송 (talk_message)`을 설정합니다.
   5. [앱 설정 > 플랫폼 > Web]에 사이트 도메인 `https://auction.maplestory.nexon.com`을 등록합니다. 메시지 안의 링크에 쓰입니다.
   6. [앱 설정 > 보안]에서 Client Secret이 켜져 있으면 그 값을 `.env`의 `KAKAO_CLIENT_SECRET`에 넣습니다. 꺼져 있으면 비워 둡니다.

5. `.env.example`을 복사해 `.env`를 만들고 값을 채웁니다.

```powershell
copy .env.example .env
```

   - `ITEM_NAME`, `POTENTIAL_OPTIONS` 같은 옵션 라벨은 옥션 화면에 보이는 이름을 그대로 적습니다. 예: `스킬 재사용 대기시간 감소:2, STR %증가:9`
   - 숫자 조건은 모두 "이상" 조건입니다.
   - `WORLD_NAME`과 `CHARACTER_NAME`은 계정에 월드나 캐릭터가 하나뿐일 때만 비워 둘 수 있습니다.
   - `KAKAO_REST_API_KEY`에는 4단계에서 복사한 REST API 키를 넣습니다.

6. 카카오 로그인을 한 번 합니다. 브라우저가 열리고 카카오 동의 화면이 나타납니다. 동의하면 토큰이 `data/kakao-token.json`에 저장됩니다.

```powershell
npm run kakao:auth
```

7. 조건이 맞는지 한 번 검색합니다. 카카오 메시지는 보내지 않고 상위 3건만 출력합니다. 검색 한도 하루 100회 중 1회를 씁니다.

```powershell
npm run search:once
```

8. 감시를 시작합니다.

```powershell
npm start
```

## 하루 운영 방법

1. 출근 후 터미널에서 `npm start`를 실행합니다.
2. 처음 실행하거나 세션이 끊겼다면 브라우저 창이 앞으로 나옵니다. 넥슨 로그인과 OTP 인증을 진행합니다.
3. 로그인이 끝나면 프로그램이 창을 최소화하고 `INTERVAL_MINUTES`(기본 15분)마다 검색합니다.
4. 시작할 때 "감시 시작" 메시지가 카카오톡으로 옵니다. 이후에는 상위 N건의 매물이나 가격이 바뀔 때만 메시지가 옵니다.
5. 퇴근할 때는 터미널에서 Ctrl+C를 누릅니다. 브라우저도 함께 닫힙니다.
6. 매물을 직접 살 때는 먼저 프로그램을 끄고, 브라우저에서 로그인해 구매합니다. 같은 계정으로 다른 곳에서 경매장에 접속하면 기존 세션이 끊깁니다.

## 문제 해결

- **"로그인이 필요합니다" 메시지가 왔습니다.** 열려 있는 브라우저 창에서 넥슨 로그인을 다시 합니다. 창을 찾을 수 없으면 프로그램을 껐다가 다시 켭니다.
- **"오늘 남은 검색이 N회라 검색을 멈춥니다" 메시지가 왔습니다.** 검색 한도가 `MIN_REMAINING_SEARCHES`(기본 10회) 이하로 남아 검색을 멈춘 것입니다. 다음 날 자동으로 다시 시작합니다.
- **카카오 토큰이 만료되었습니다.** 카카오 refresh 토큰은 약 2개월이 지나면 만료됩니다. `npm run kakao:auth`를 다시 실행합니다.
- **`[설정 오류]` 줄이 출력됩니다.** `.env`의 해당 항목을 고칩니다. 메시지에 쓸 수 있는 값이 함께 나옵니다.
- **브라우저 창을 손으로 닫았습니다.** 프로그램을 껐다가 다시 `npm start`로 켭니다.
- 검색 한도는 하루 100회입니다. 조건을 자주 바꿔 맞춰 보면 금방 소진되니 `npm run search:once`는 필요할 때만 씁니다.
